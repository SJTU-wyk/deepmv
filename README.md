# DeepMV

打开网页就能用的影视资源导航。搜一个片名，它同时去十几个数据源找，告诉你哪里能看、画质多高、这条线路现在还通不通。

在线地址：<https://deepmv.onrender.com>

免费实例闲置十几分钟会休眠，第一次打开可能要等半分钟才响应。

## 能做什么

**搜片** —— 输入片名，十几个来源同时查。同名结果会合并成一条，点开能看到它在几个源里有。

**看真实画质** —— 站点的"HD""超清"标签经常不准。这里读的是视频文件自己声明的分辨率，角标上显示的是实测值。

**挑线路** —— 每条线路标着可用、未验证或暂不可用。点「检查线路可用性」会实际探一遍，探过的结果会记住一段时间，不用每次都等。

**去广告** —— 视频清单里被插进去的广告片段会被切掉。注意：烧在画面上的广告去不掉，那种只能换个源。

**看剧集** —— 按集切换，自动记忆看到哪一集。

**片单** —— 国产经典、欧美影史名片、口碑剧集这些整理好的列表，点进去直接是多源解析好的结果。

**网盘** —— 部分片源附带百度、夸克、迅雷的分享链接。链接要你自己的网盘账号才能打开。

## 怎么用

打开网址，输入片名。

不用注册，不用装客户端。手机上用浏览器打开后选"添加到主屏幕"，全屏显示，跟 App 差不多。

搜索结果里的卡片点进去是详情页，详情页有两个按钮：播放第一集，检查线路可用性。

## 关于画质

站点标的"1080P"不能全信。同一部《霸王别姬》，有的源标 1080P，清单里只有 1280x692。

所以这里读的是 HLS 视频清单里的 `RESOLUTION` 字段，那是片源自己声明的，比网页上印的标签可靠。

## 播放不了怎么办

按顺序试这三个：

1. 详情页点「检查线路可用性」，看哪条标着可用
2. 换一条线路（详情页上方有线路列表）
3. 换一个来源（详情页下方「其它来源」里是同片的其它源）

如果一条都不行，大概率是那个片源整体挂了。第三方接口的可用性不由本站控制。

## 自己部署

### 用自己的服务器（推荐，能长期在线）

一台 Ubuntu 22.04 或 24.04 的机器，一条命令：

```bash
curl -fsSL https://raw.githubusercontent.com/SJTU-wyk/deepmv/master/deploy/install.sh -o install.sh
sudo bash install.sh --domain 你的域名 --email 你的邮箱
```

没域名就直接 `sudo bash install.sh`，先用 IP 加自签证书跑通。

脚本会装 Node、构建前端、注册 systemd 服务、配 Caddy 自动 HTTPS、开防火墙、装健康检查。跑完会把访问地址打出来。再跑一次等于更新。

详细步骤（含微软云的建机流程）见 [deploy/AZURE.md](deploy/AZURE.md)。

### Render 免费版

仓库里有 `render.yaml`。在 Render 选 New → Blueprint，指向这个仓库，几分钟后拿到一个 https 地址。

### 本地跑

```bash
pnpm install --config.strictDepBuilds=false
pnpm build && pnpm start
```

打开 <http://127.0.0.1:7821>。本地模式只监听本机，同局域网的其它设备也连不上。

## 给站点加口令

默认是公开的，谁拿到地址都能用。想只给熟人用就设一个口令：

```bash
# 自己的服务器：/etc/deepmv.env
DEEPMV_KEY=你想用的口令

# Render：面板的 Environment 里加一条
```

设了之后打开网址要带 `?key=你的口令`，浏览器会记住。

## 常见问题

**为什么有的搜索结果只有一两条？**

那个片名可能比较冷门，或者大部分源暂时不可用。详情页的「其它来源」里能看到同片的其它源。

**为什么提示"当前访问的人有点多"？**

触发了限流。正常浏览不会碰到，通常是同一时间请求太密集。等一分钟再试。

**为什么画质比别的站低？**

本站显示的是实测分辨率。如果这里显示 540P，说明那个源确实只有 540P，换个源可能更高。

**支持下载吗？**

不支持。只有在线播放和网盘链接。

**手机上能装吗？**

可以。浏览器打开后选「添加到主屏幕」，iOS 和 Android 都支持。
